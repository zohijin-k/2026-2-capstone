## 이후 구현 검증 명령
실행 전 테스트 수집/코드를 확인하여 금지 자료에 접근하는지 검토한다. 민감 자료를 여는 시험은 실행하지 않고 안전한 실행 대상을 명시한다. 금지 경로는 명령 인자로도 사용하지 않는다.

```sh
.venv/bin/python -m pytest engine_v2/tests
.venv/bin/python -m pytest demo/backend/tests
.venv/bin/python -m demo.backend.tests.run_p2_scenarios
```

- 사용자 제공 비교 기준: engine_v2 260 passed / 3 skipped, P2 53 passed. 이번에는 측정하지 않았다.
- demo/backend는 독립 시나리오 관례도 있으므로 pytest 수집이 비어 있으면 이를 보고하고 해당 run_p*_scenarios.py 목록과 안전한 실행 방법을 확정한다.
- 집중 검증: 기존 NHIS 추출·연속 페이지·최근 5년 회귀, 새 공단 좌표/PDF/API 시험, 파일명/expected 무관성.
- 자산 없는 환경에서 이미지 통합은 기존 skip 관례, 좌표 단위 시험은 무조건 실행.
