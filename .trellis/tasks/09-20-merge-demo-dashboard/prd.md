# demo · dashboard 통합

## 배경

저장소가 담당자별로 잘려 있다 — `engine/`(진) · `demo/`(지빈) · `dashboard/`(채운). 그래서 `demo/`만 backend+frontend를 품는 2계층이고 나머지는 1계층이라 트리가 비대칭이다. 설치 진입점이 3곳(`npm install` ×2, `pip install` ×1)으로 흩어져 있고, 루트 `README.md`는 아직 "대시보드는 별도 합류 예정"이라고 적혀 있다.

실제 결합은 느슨하다. `engine/`은 파일 I/O·네트워크가 0인 순수 계산 모듈이고 바깥을 전혀 참조하지 않는다. `demo → engine` 단방향 결합이 `engine_adapter.py` 한 파일에 모여 있고, `dashboard`는 아무것도 참조하지 않는다. 즉 구조 문제는 **결합이 아니라 배치**다.

## 요구사항

### R1. 프론트 단일 앱

두 Vite 앱을 하나로 합친다. 상단 탭 3개 — 신청자 / 담당자 / **현황**.

- R1.1 기존 신청자·담당자 화면의 **동작과 외형이 한 픽셀도 바뀌지 않는다.** 특히 서식 재현 화면(940px 고정, 맑은 고딕, 행간 1.6)은 원형 재현물이므로 폰트·행간·선 농도가 달라지면 실패로 본다.
- R1.2 탭을 오가도 작성하던 내용이 유지된다(기존 `demo/frontend/src/App.tsx`의 설계 의도).
- R1.3 대시보드의 기존 링크 파라미터 `?date= region= theme=`가 계속 동작한다.
- R1.4 npm 패키지는 1개가 된다. `dashboard/` 폴더는 사라진다.

### R2. 대시보드 백엔드 연동 (하이브리드)

- R2.1 실데이터가 있으면 실데이터를, 없거나 조회에 실패하면 목업을 보여준다. **배타적 전환이며 섞지 않는다.**
- R2.2 지금 어느 쪽을 보고 있는지 화면에 항상 표시된다. 목업임을 숨기지 않는다(저장소 기존 규약).
- R2.3 `?data=mock|live`로 강제 전환할 수 있다.
- R2.4 신청자 탭에서 1건 제출하면 현황 탭 숫자가 오르는 것을 시연할 수 있다.
- R2.5 **실데이터로 산출할 수 없는 지표는 "0"이 아니라 "해당 없음"으로 표기한다.** 0으로 그리면 "심사가 하나도 안 됐다"는 거짓 정보가 된다.

### R3. 배점·커트라인 접근 제한

배점 분포와 커트라인은 담당자만 본다.

- R3.1 **프론트에서 숨기는 것만으로는 부족하다.** 권한이 없으면 서버 응답에 해당 필드가 아예 포함되지 않아야 한다.
- R3.2 데모에는 로그인이 없다. 이것이 **권한이 아니라 권한 구조의 시연**임을 응답과 화면에 명시한다.

### R4. 구조·문서 정리

- R4.1 루트 코드 디렉터리를 `engine/` + `demo/` 둘로 정리한다.
- R4.2 설치·기동·검증을 루트에서 한 가지 방식으로 건다.
- R4.3 루트 `README.md`의 폴더 구조 섹션을 현재 상태에 맞게 다시 쓴다.
- R4.4 `demo_run.py`를 제자리로 옮기고 종료코드로 성패를 알 수 있게 한다.

### 판정

- **A1** `python -X utf8 -m demo.backend.tests.run_p{2..7}_scenarios` 6종이 **위 기준선과 같은 통과 수**로 끝난다. 줄어들면 실패.
- **A2** `npm run build`·`npm run lint`가 통과하고, **메인 청크가 500KB 미만**이다(단순 병합 시 ~1.7MB가 되므로 분할 없이는 불가).
- **A3** `npm run test:engine`이 assert 기반으로 8개 시나리오를 검사하고 종료코드로 성패를 알린다.
- **A4** `npm run setup` → `dev:api` → `dev:web` 3줄로 새 PC에서 기동된다.
- **A5** 육안 — ① 담당자 접수목록 표가 정상 ② 신청자 서식1의 폰트·행간·940px 불변 ③ 현황 탭 차트 6개 정상 ④ 다크모드가 현황 탭에만 적용 ⑤ **현황 탭을 먼저 연 뒤 담당자 탭에 실데이터가 뜬다** ⑥ 신청 1건 제출 → 현황 숫자 증가.
- **A6** 권한 없는 요청의 응답 본문에 배점·커트라인 필드가 **존재하지 않는다**(값이 null인 것으로는 불충분).
- **A7** `git log --follow`로 이동한 파일의 히스토리가 이어진다.
- **A8** 루트 README의 명령을 위에서부터 그대로 복붙해 기동된다.
