## Definition of Done

- [ ] 두배적금 신청을 **자필서명·종이 없이** 처음부터 끝까지 완주할 수 있다
- [ ] 발급 서류(초본·건보 3종·근로확인)만 파일 업로드이고 나머지는 전부 웹 입력이다
- [ ] 업로드 후 **5초 이내** 적합/부적합/확인필요가 표시된다
- [ ] 근로유형을 바꾸면 요구 서류 목록이 자동으로 바뀐다
- [ ] 심사표 100점이 시행지침 서식6과 **수기 검산에서 일치**한다
- [ ] 담당자가 심사 1건을 처리하는 동안 파일 다운로드가 **0회**다
- [ ] 판정 근거를 클릭하면 원본의 해당 위치가 하이라이트된다
- [ ] 신청자 화면 어디에도 심사 점수가 노출되지 않는다
- [ ] 취업패키지 복수 항목 신청과 실비 계산이 동작한다
- [ ] 10개 시연 시나리오가 리셋 후 재현된다
