# 설계

- 기준: `CRITERIA_SCHEMA_VERSION`을 증가시키고 `paper_forms` 맵을 현재 기본값과 병합해 읽는다. 신청서는 저장된 기준 버전을 그대로 참조한다.
- 모드: 신청서의 기존 문서 컨텍스트 JSON에 종이 제출 선택을 저장한다. 변경 API는 초안만 허용하고 해당 서식이 기준상 허용되는지 검증한다. 체크리스트는 해당 모드에서만 `admin_info_consent`를 업로드 필수로 만든다.
- 다운로드: forms API에 이름이 있는 빈 템플릿/작성본/HWP/zip 응답을 추가한다. 기존 담당자 PDF/파일 링크 API는 유지한다. `manifest.json`은 안전한 상대 파일명만 담고 목록·ZIP도 manifest를 기준으로 한다.
- 스캔 판정: 기존 `ADMIN_INFO_CONSENT` 업로드 슬롯과 문서 타입 탐지 경로를 사용한다. 제목 특징으로 타입을 판별하고 이름·생년월일을 본인인증 값과 대조한다. 체크·잉크 검출을 별도 필드와 finding으로 보존하고 손글씨 판독 불확실은 재검토로 둔다.
- UI: PdfFormsWorkspace 카드 메뉴와 방식 선택을 추가하고, ApplyFlow에서 저장된 선택과 업로드 체크리스트 갱신을 연동한다. 기존 작성 값/서명 데이터는 모드 변경 때 삭제하지 않는다.
