## P7. 작성 서식 PDF 내보내기 (D+21 ~, **선택**)

> **메인 기능이 아니다.** P6까지 끝나고 시간이 남을 때만 착수한다. 미구현이어도 DoD에 영향이 없다.

- [ ] 원본 PDF에서 서식1·서식5를 **논리 쪽 단위로 잘라** `fixtures/templates/`에 저장 (⚠️ 2-up)
- [ ] `fixtures/form_coords/서식1.json`, `서식5.json` 좌표 맵 작성
- [ ] `backend/forms/render.py` — PyMuPDF `insert_text()` / `insert_image()` 오버레이
  - [ ] `type: "check"` — 체크박스 좌표에 `✓`
  - [ ] `type: "image"` — 서식5 서명란에 캔버스 PNG 합성 (R9.2)
- [ ] `GET /api/applications/{id}/forms/{form_no}.pdf` — 인라인 응답 (R9.3)
- [ ] 담당자 심사 화면 서류 탭에 **"작성 서식" 탭** 추가 — 업로드 서류와 나란히 브라우저에서 확인

**게이트**: 서식1·서식5 PDF를 내려받아 원본과 겹쳐 봤을 때 항목 위치가 어긋나지 않는다. 다운로드 없이 담당자 화면에서 열린다.
