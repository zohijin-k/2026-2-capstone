# 취업지원패키지 분기 및 시연 준비

**부모 태스크**: `.trellis/tasks/09-16-demo-site/`
**담당 Phase**: P5 · P6 · P7(선택)
**요구사항 원본**: 부모 `prd.md` R6·R9 / 설계는 부모 `design.md` 6·6-B

## Goal

같은 파이프라인으로 **사업만 바꾸면 동작한다**는 것을 취업지원패키지로 증명하고, 시연 시나리오 10종을 리셋 후 무중단 재현 가능한 상태로 만든다.

## Scope

| 포함 | 제외 |
|---|---|
| 사업 분기 (`ProgramConfig` 취업패키지 값) | 신청자 화면 골격 → `09-16-demo-applicant` |
| 지원 항목 복수 선택 + 실비 계산 | 담당자 분할 심사 뷰 → `09-16-demo-officer` |
| 선착순 표시 · 7일 보완 기한 | |
| fixture 10종 · 리셋 스크립트 · 시연 대본 · README | |
| **(선택)** 서식1·5 PDF 내보내기 (P7) | 서식2~4 PDF — 좌표 맵 구조만 남김 |

## 두배적금과 다른 점 (구현 분기점)

| 항목 | 두배적금 | 취업지원패키지 |
|---|---|---|
| 선발 | 점수제 100점 + 시군 정원 | **선착순**, 예산 소진 시 조기마감 |
| 보완 | **불가** | **7일 내 보완**, 미보완 시 후순위자 교체 |
| 연령 | 2025-12-31 기준 (1986.1.1.~2007.12.31.) | 2026년 기준 (1987.1.1.~2008.12.31.) |
| 소득요건 | 중위소득 140% 이하 | **없음** |
| 서류 인정일 | 2026-03-03 이후 | **2026-01-01 이후** |
| 신청 단위 | 1회 | **항목별 복수 선택** |

**지원 항목 한도**: 면접비 5만원/회 최대 2회(**정액**, 영수증 불요) · 정장 대여 5만원 최대 2회(실비) · 면접사진 2만원 1회(실비) · 자격증 응시료 5만원 최대 2회(실비, **응시일 표기 필수**)

## 선행 조건

`09-16-demo-applicant`(P0~P3)가 끝나 `ProgramConfig` 분기 구조와 업로드·판정 파이프라인이 있어야 한다.

## Acceptance Criteria

- [ ] 사업을 바꾸면 연령 기준·서류 인정일·소득요건 유무가 자동으로 달라진다
- [ ] 지원 항목 복수 선택 시 항목별 추가서류 체크리스트가 조립된다
- [ ] 실비 계산이 맞다 — 정장 영수증 35,000원 → 35,000원 / 70,000원 → 50,000원
- [ ] 면접비는 영수증 없이 면접확인서만으로 정액 5만원이 계산된다
- [ ] 응시확인서·성적표에 **응시일 표기가 없으면** FAIL 처리된다
- [ ] 선착순 표시와 7일 보완 기한 카운트다운이 보인다
- [ ] 리셋 후 **10개 시연 시나리오가 무중단 재현**된다
- [ ] 미확정 가정값이 화면과 코드에 `(데모 추정치)` 라벨로 명시되어 있다
- [ ] `demo/README.md`에 기동 방법이 있다

**선택 (P7 — 미구현이어도 완료 판정에 영향 없음)**

- [ ] 서식1·서식5를 작성된 상태 그대로 PDF로 내보낼 수 있다
- [ ] 서식5 PDF의 서명란에 전자서명이 합성되어 있다
