# 본인인증 서명 UI 정리

## 목표

두배적금 첫 본인인증 화면의 서명 영역에 단계 2 서식 5의 서명 UI를 일부 적용한다. 서명 영역은 본인인증 화면 안에 표시한다.

## 수용 기준

- 직접 서명과 서명 파일 올리기를 서식 5처럼 탭으로 전환할 수 있다.
- 서명 입력 영역과 하단 지우기 동작이 서식 5의 시각적 구성과 일관된다.
- 직접 서명과 업로드 파일의 미리보기 및 재선택이 화면 안에서 작동한다.
- 기존 동의 체크, 파일 형식 및 크기 제한, 본인인증 제출 조건과 서버 전송 형식이 유지된다.
- 작은 화면에서도 서명 영역이 가로로 넘치지 않는다.
