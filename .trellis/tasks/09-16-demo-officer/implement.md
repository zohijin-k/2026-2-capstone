## P4. 담당자 화면 — 다운로드 0회 (D+12 ~ D+16)

- [ ] `GET /officer/applications` — 필터(사업·시군·상태·AI판정·신청일) + 정렬 + 페이징 (R4.4)
- [ ] 접수 목록 UI — 컬럼(신청번호·성명·시군·AI판정·점수·미비서류수·접수일시), 일괄 승인/반려
- [ ] 시군별 정원 대비 진행률 배지 (전주 550 … 진안 15)
- [ ] `GET /api/files/{doc_id}` — `Content-Disposition: inline` 스트리밍 (R4.1)
- [ ] 분할 심사 뷰 — 좌 55% pdf.js 뷰어 / 우 45% AI 판독 결과 (R4.2)
  - [ ] 서류 탭 전환, 확대/회전, **다운로드 버튼 없음**
  - [ ] 심사표 항목 클릭 → 좌측 해당 위치 스크롤 + bbox 하이라이트 (R4.3)
  - [ ] 자격요건 체크리스트 / 제외대상 조회 결과 / 부적합 사유
  - [ ] 심사표를 **서식6 원본 배점표 레이아웃**으로 렌더 — 자동 계산 점수 칸에 배경색 + 근거 문장 (R8.7)
  - [ ] [승인][반려][보류] + 담당자 메모
- [ ] 역할 전환 토글 — 읍면동 / 시군(120% 선발) / 도·청년허브(2차검증 100%) (R4.5)

**게이트**: S9 시연 중 브라우저 네트워크 탭에 **다운로드 0건**. 점수 근거 클릭 → 원본 하이라이트 동작.
