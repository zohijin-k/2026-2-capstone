**게이트**: ✅ **통과 (2026-09-16)**
- `python -m demo.backend.tests.run_p4_scenarios` — 165개 검증 항목 전부 통과 (실패 0). 회귀로 `run_p2_scenarios`(48) · `run_p3_scenarios`(109)도 여전히 전부 통과
- **다운로드 0건 (P4 핵심 게이트)**: 심사 1건을 여는 전 구간(목록 → 상세 → 서류 5건 원본 → 근거 클릭 재조회)에서 오간 응답 12건을 전부 기록해 검사. `attachment` **0건**, `Content-Disposition`이 붙은 응답은 **전부 `inline`**, 원본 스트리밍 8회 모두 `inline; filename*=UTF-8''…`
- 정적 검사로도 이중 확인: `demo/backend`·`demo/frontend/src` 전체에서 `attachment` / `download` 속성 / blob 저장 토큰 **0건**. 뷰어는 pdf.js가 `/api/files/{id}`를 직접 읽고, 화면에 저장 버튼이 없다
- **근거 클릭 → 원본 하이라이트**: 심사표 4개 항목 전부 `source_document_id`가 실재하는 서류로 해석된다 (중위소득→납부확인서 `/api/files/2`, 거주기간·연령→초본 `/api/files/1`, 근로기간→4대보험 `/api/files/5`). 중위소득·거주기간은 `bbox` 4점+페이지가 유효한 사각형이고, 그 좌표로 연 원본이 200 + `inline`
- **필터가 실제로 건수를 바꾼다**: AI판정 적합 2 / 부적합 1 / 확인필요 1, 사업 두배적금 4 / 취업패키지 0, 신청일 상·하한 4→0, 시군 전주 3 / 군산 1 / 진안 0. 잘못된 값은 400
- 정렬: 점수순 `[99, 99, 99, 87]` vs 접수순 — 결과 순서가 실제로 다름. 페이징 2건×2쪽, 페이지 간 중복 0
- **역할 3종이 실제로 다르다**: 보이는 건수 읍면동(효자동) 2 → 시군(전주) 3 → 도 4. 읍면동을 인후동으로 바꾸면 1건으로 바뀐다. 같은 `approve`라도 버튼이 "구비서류 완비 확인" / "1차 선발(120%)" / "최종 선정(100%)"으로 갈리고, 읍면동 일괄 처리 시도는 403
- 승인/반려/보류 + 메모가 DB(`officer_role`·`officer_decision`·`officer_memo`·`decided_at`)에 기록되고 목록 처리상태가 따라 바뀐다. 보류는 `decided`가 아닌 `reviewing`으로 남는다
- 담당자 화면이 생겨도 신청자 `/status`에는 총점·점수 키·담당자 메모가 여전히 없다 (R5.3 회귀)
- `tsc -b` · `oxlint` 무경고 (exit 0) · `vite build` 성공
- 검증 스크립트는 DB·업로드 저장소를 임시 경로로 격리 — 실행 전후로 `demo/demo.db`·`demo/storage` 변경 없음

**P4에서 남긴 것**
- 심사표 4개 항목 중 `bbox`까지 붙는 것은 **중위소득·거주기간 2개**다. 근로기간·연령은 근거 서류(`source_document_id`)까지만 이어지고 좌표가 없어 클릭 시 해당 서류 탭만 열린다 — fixture 판독값에 취업일·생년월일 좌표가 없기 때문이고, OCR Tier2 필드가 늘면 자동으로 채워진다
- 제외대상 조회는 행복e음·일모아 **미연동**(부모 prd.md C3)이라 자가진단 답변 + 엔진 2단계 판정으로 같은 자리를 채웠다. 실연동 시 각 행의 `source`만 바뀐다
- 역할은 로그인이 아니라 셀렉트 토글이다(C3). 관할(시군·읍면동)을 고르지 않으면 접수 건이 있는 첫 관할을 자동 선택해 시연이 빈 화면에서 끊기지 않게 했다
- 목록·정렬·정원 계산은 전건을 파이썬 메모리에서 처리한다. 동점자 우선순위가 SQL `ORDER BY`로 표현하기 어려운 복합 키인데다 데모 규모에서는 비용이 없다 — 실서비스로 옮길 때 `tiebreak_json`을 정렬 컬럼으로 승격할 자리다
- 취업지원패키지 분기(보완 기한 UI 등)는 `09-16-demo-jobpkg` 소관이라 목록 필터·접수순 정렬까지만 넣었다
