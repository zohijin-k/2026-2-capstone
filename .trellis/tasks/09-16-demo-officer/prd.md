# 담당자 심사 화면 — 다운로드 0회 분할 뷰

**부모 태스크**: `.trellis/tasks/09-16-demo-site/`
**담당 Phase**: P4
**요구사항 원본**: 부모 `prd.md` R4·R8.7 / 설계는 부모 `design.md`

## Goal

담당자가 **파일을 한 번도 내려받지 않고** 브라우저 안에서 원본 서류와 AI 판독 결과를 나란히 보며 심사를 끝낸다. 판정 근거를 클릭하면 원본의 해당 위치가 하이라이트된다.

## Scope

| 포함 | 제외 |
|---|---|
| 접수 목록 (필터·정렬·페이징·정원 배지) | 통계·시각화 → 대시보드(채운) 영역 |
| 인라인 파일 스트리밍 + pdf.js 뷰어 | 신청자 화면 → `09-16-demo-applicant` |
| bbox 하이라이트, 서식6 레이아웃 심사표 | 취업패키지 보완 기한 UI → `09-16-demo-jobpkg` |
| 승인/반려/보류 + 메모, 역할 전환 토글 | 실제 권한 인증(로그인) — 셀렉트 토글로 대체 |

**경계**: 데모 = 건별 심사, 대시보드 = 집계·통계. 목록 화면의 정원 대비 진행률 배지까지가 이 태스크의 한계선이다.

## 선행 조건

`09-16-demo-applicant`의 P3이 끝나 `review_payload` + `ScoreSheet`(`basis`·`source_doc`·`bbox` 포함)가 DB에 쌓여 있어야 한다. 그 전에는 fixture 데이터로 화면만 먼저 짤 수 있다.

## Acceptance Criteria

- [ ] 심사 1건을 처리하는 동안 파일 다운로드가 **0회**다 (브라우저 네트워크 탭으로 확인)
- [ ] 좌 55% 원본 / 우 45% 판독 결과 분할 뷰가 동작한다
- [ ] 심사표 항목 점수를 클릭하면 좌측 원본이 해당 위치로 스크롤되고 bbox가 하이라이트된다
- [ ] 심사표가 **서식6 원본 배점표 레이아웃**으로 보이고, 자동 계산 칸에 근거 문장이 붙어 있다
- [ ] 사업·시군·처리상태·AI판정·신청일 필터와 점수순 정렬이 동작한다
- [ ] 시군별 정원 대비 진행률 배지가 표시된다 (전주 550 … 진안 15)
- [ ] 역할(읍면동 / 시군 / 도·청년허브)을 바꾸면 목록 범위와 가능한 액션이 달라진다
- [ ] 화면 어디에도 다운로드 버튼이 없다
