# 실행 계획

## 1단계: 템플릿·맵·내보내기

1. 원본 PDF 각 쪽의 제목과 A4 크기를 검증하고 여덟 템플릿을 만든다.
2. 좌표 생성기를 실제 원본 쪽·저장 키·예시 가림 영역에 맞춘다.
3. 좌표 맵 로더와 PDF 렌더러에 모든 신청자 서식과 예시 제거를 연결한다.
4. API와 담당자 작성본 목록에서 두 사업의 신청서·동의서를 인라인 PDF로 제공한다.
5. 합성 값 테스트로 좌표, 쪽 경계, 겹침, 재추출 글자, 예시 제거를 검증한다.
6. P7 및 전체 백엔드 시나리오와 engine_v2 테스트를 실행한다.
7. 루트 원본·개인정보가 제외됐는지 확인한 뒤 1단계 커밋을 만든다.

## 2단계: 작성·미리보기·재작성

1. 저장 키를 좌표 필드로 바꾸는 공통 입력 팝업과 양식 상태 목록을 만든다.
2. 신청·자가진단·동의 서식을 팝업으로 전환하고 기존 웹 폼·사용하지 않는 CSS를 제거한다.
3. 본인인증 값, 작성일, 자필/전자 서명, 체크·라디오, 필수 항목 탐색을 연결한다.
4. 취업패키지 지원 항목·지역·면접/정장 연결과 면접확인서 보기 기능을 연결한다.
5. 화면 미리보기와 제출 후 서버 편집 잠금을 구현한다.
6. 담당자 작성본 탭, API 시나리오, 프론트 검사와 합성 값 캡처를 점검한다.
7. 두 번째 커밋을 만든다.
