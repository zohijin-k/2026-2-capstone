# 근거 점검

- 기존 own OCR 문서: 엔진 후보·고정 모델·글꼴 분리·평가 정의·보정 실험·형식 추출 수정.
- 기존 classifier 문서와 분류 작업 보고: 합성 학습은 완료, 운영 연결은 미실시. 고정 임계값의 보류율 문제와 학습 자료만을 이용한 향후 확률 보정 필요.
- 추출 진단 보고: 합성 입력의 대시 정규식·행 분리·고정 영역 문제. 형식 수정 보고: 명조 네 조건 모두 회복.
- fetch 코드: 모델 배포 버전·URL·SHA256, 글꼴 고정 커밋 및 라이선스 고지 확인.
- git log 날짜: 주요 OCR·평가·분류·수정 커밋은 모두 2026-11-11.
- 요구 문구의 확정 원문은 검색한 저장소 문서에 없음. 본문에서 확인된 요구 사실로 주장하지 않고 기록 없음 목록에 둔다.
- 인식 미세조정 지연의 구체적 의사결정 사유는 기록 없음. 준비된 평가 작업과 향후 검증 조건까지만 설명한다.
- 기존 문서의 외부 서비스 상태 설명은 새 문서에 옮기지 않는다. 실서류 평가의 수치나 식별 정보는 수집·복사하지 않는다.
