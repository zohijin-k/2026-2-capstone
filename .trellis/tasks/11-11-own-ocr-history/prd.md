# 목적과 범위

공개 저장소의 심사위원·기관 담당자·후속 개발자를 위한 한국어 제작 과정 문서를 작성한다. 새 본문은 200줄 이내이며 지정된 구성과 표, 용어 풀이, 저장소 근거를 갖춘다. 기존 OCR 문서는 맨 위 링크 한 줄만 추가한다. 그 외 쓰기는 이번 작업 폴더로 제한한다.

저장소에서 확인한 사실과 기존 문서 수치만 사용한다. 미확인 요구 원문·실험·성과는 기록 없음 목록으로 분리한다. 실서류 값·인식 문구·입력 파일명·경로와 인증정보는 기록하지 않는다. 외부 OCR 서비스는 사용자가 허용한 설명 한 줄만 사용한다.

코드·테스트·README·백엔드·spec·workflow를 수정하지 않는다. 기준과 최종 pytest 통과 수가 같고 실패가 없어야 지정 메시지로 커밋한다. 병합·amend·push·공동저자 줄을 추가하지 않는다.
