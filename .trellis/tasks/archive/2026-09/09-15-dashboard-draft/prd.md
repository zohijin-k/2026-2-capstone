# 현황 대시보드 프론트엔드 초안

## Goal

담당자(전북특별자치도·시군·청년허브센터) 첫 미팅에서 보여줄 「전북청년 함께 두배적금」 신청·심사·선정 현황 대시보드 프론트엔드 초안. 백엔드/엔진 연동 없이 목업 데이터로 동작한다.

## Requirements

- 위치: 저장소 루트 `dashboard/` (Vite + React + TypeScript). `engine/`은 수정하지 않는다.
- 목업 데이터는 '26년 실제 규모를 기준으로 결정론적으로 생성한다.
  - 시군별 접수인원(총 12,821건)·선정 정원(1,300명), 신청기간 3.3~3.16, 발표 5.15
  - 심사표 배점: 중위소득 40 / 도 거주기간 25 / 근로기간 25 / 연령 10, 동점자 우선순위 규칙
  - 부적합 사유는 공고문 미비 사례·콜센터 문의 유형(초본/등본, PDF 암호 등)을 반영
- 한 화면에서 볼 수 있어야 하는 지표
  - 접수 현황(일별/누적 접수 건수 — 작성 시작 등 알 수 없는 값은 쓰지 않음), 시군별 신청자 수, 정원 대비 접수율, 경쟁률
  - 선정자 수, 심사 진행률(시군별 단계), 평균 처리기간, 부적합 사유
  - 신청자 평균 연령·연령대 분포, 성별, 근로유형·건강보험 가입유형·가구원 수
  - **담당자용**(맨 아래, 구분선으로 분리): 배점(총점)별 신청자 분포, 시군별 선정 커트라인. 배점 관련 정보는 이 영역 밖에 두지 않는다.
- 전북 14개 시군만 표시하는 지도(코로플레스). 지표 전환 가능, 클릭 시 시군 필터.
- 기준일 슬라이더(3.3~5.15)로 접수→심사→선정 진행 상황을 시점별로 재현, 자동 재생.
- 시군 필터 1개를 필터 바에 두고 모든 관련 차트가 같은 범위로 갱신.
- 라이트/다크 테마, 좁은 화면에서 1열로 재배치.

## Acceptance Criteria

- [ ] `npm run build`(타입체크 포함)와 `npm run lint`가 오류 없이 통과한다.
- [ ] 위 지표가 모두 화면에 표시되고, 기준일·시군 필터 변경 시 일관되게 갱신된다.
- [ ] 지도에 전북 14개 시군 경계가 표시되고 클릭으로 시군을 선택/해제할 수 있다.
- [ ] 발표일 기준 선정자 합계가 1,300명, 시군별 선정 인원이 정원과 일치한다.
- [ ] 목업 데이터임이 화면에 명시된다.

## Notes

- 목업 분포(연령·성별 등)는 콜센터 만족도 조사 응답 비율 등을 참고한 가정값이며 실제 통계가 아니다.
- 커트라인 예상 = 판정 완료 건의 적합률을 미판정 건에 적용해 정원을 채우는 최저 총점. 2차 검증 이후에는 확정값.
