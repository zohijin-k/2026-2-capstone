# 사용 설명서

이 문서는 신청자와 담당자가 데모를 이용하는 방법을 설명합니다. 데모의 화면과 처리 결과는 실제 행정 시스템의 최종 서비스가 아닙니다. 데모에는 가상 신청 정보와 가상 서류만 사용합니다.

## 신청자

### 1. 사업 선택과 로그인

첫 화면에서 사업을 선택하고 데모 본인인증 단계를 진행합니다. 실제 인증기관에 연결된 로그인은 아닙니다. 신청 중 상단의 신청번호 옆 버튼으로 마이페이지를 열어 진행 상태를 볼 수 있습니다. 사업마다 신청 항목, 제출 서류, 인정 날짜와 절차가 다르므로 먼저 안내를 확인하세요.

### 2. 신청서 작성과 서류 올리기

화면 안내에 따라 신청 내용을 입력하고 동의 항목을 확인합니다. 온라인 작성 화면은 공고 서식의 원본 PDF 위에 입력 내용을 표시합니다. 함께 두배적금은 서식5를 온라인으로 작성하거나 스캔본 제출을 선택할 수 있습니다.

서류 화면에서 각 업로드 칸에 안내된 서류를 선택합니다. PDF, JPG, PNG 파일을 받습니다. 암호가 걸린 PDF는 먼저 암호를 해제해야 합니다. 발급일을 묻는 칸에서는 서류의 발급일을 입력하고 화면에 나온 인정 기준을 확인하세요. 파일 이름이 아니라 서류 본문을 읽어 종류를 확인합니다.

### 3. 결과 보기

업로드 뒤 칸별로 결과가 표시됩니다.

| 화면 표시 | 뜻 |
|---|---|
| 확인 완료 | 자동 검사에서 확인된 항목을 통과했습니다. |
| 담당자 확인 예정 | 자동 판독만으로 단정하기 어려워 담당자가 원본을 확인합니다. 제출은 계속할 수 있습니다. |
| 다시 올려 주세요 | 필요한 서류가 아니거나 기준과 다른 내용이 확인됐습니다. 안내에 따라 고쳐 올리세요. |

최종 확인 화면에서 입력 내용을 확인하고 제출합니다. 자격 판정과 담당자 검토 결과는 마이페이지 등 데모 화면에 표시됩니다. 함께 두배적금 점수와 내부 배점은 신청자 화면에 표시하지 않습니다.

### 4. 보완 요청을 받은 경우

사업별 보완 절차가 다릅니다. 데모 기준상 취업지원패키지는 보완 대상 서류를 7일 안에 보완하는 절차가 있고, 함께 두배적금은 보완 요청 없이 미비 시 선발에서 제외되는 흐름입니다. 화면에 표시된 대상 서류와 안내를 확인하세요. 현재 데모는 상태와 안내를 보여 주지만 모든 실제 업무 절차를 대신하지 않습니다.

### 5. 서식 내려받기와 온라인 작성

서식 작성 화면의 다운로드 메뉴에서 작성한 서식 PDF 한 파일 또는 원본 한글 문서(HWP, 한글 워드프로세서 파일)를 받을 수 있습니다. 두배적금 서식5는 온라인 작성 외에 스캔본 제출 방식도 선택할 수 있습니다. 온라인 작성 서식은 입력한 현재 저장 상태를 반영합니다.

### 6. 종이 제출 서류

신청서와 동의서 등 온라인 작성 서식은 원본 PDF 위에서 작성하므로 별도 업로드 칸이 없습니다. 담당자 화면은 신청 목록, 판정 상세와 원본 확인으로 이어집니다. 관리자 데모 화면에서는 첫 화면에서 사업별 심사 기준과 버전 이력을 확인할 수 있습니다. 다만 사업별로 발급받아 올려야 하는 증빙 서류가 있습니다. 어떤 서류가 필요한지는 아래 사업별 목록과 화면의 체크리스트를 따르세요. 제출 방식은 공고와 담당 기관의 안내가 우선합니다.

## 담당자

### 신청 목록과 확인필요 항목

담당자 화면에서 사업별 신청 목록을 확인합니다. 목록에는 서류별 상태가 표시됩니다. `확인필요` 항목이나 부적합 사유를 확인하고 해당 신청을 열어 원본과 판독 근거를 살펴봅니다. 목록의 서류 칸을 선택하면 해당 서류가 열린 상태로 상세 화면으로 이동합니다.

### 원본 서류 확인

상세 화면에서 서류 탭을 선택하면 원본 서류와 판독 결과를 함께 볼 수 있습니다. 판독 근거가 있는 경우 어떤 내용으로 판단했는지 비교합니다. 데모 담당자 화면에서는 업로드 원본을 브라우저에서 확인하며 다운로드하지 않습니다. 판독 결과가 불확실하면 원본을 기준으로 판단합니다.

### 승인·보완 안내 문구

원본 확인 뒤 담당자 권한에 맞는 처리 버튼(예: 서류 완비 확인, 1차 선발, 최종 선정, 보류, 반려)을 선택하고 `담당자 메모 (판단 근거·확인 사항)` 칸에 내용을 적을 수 있습니다. 화면에는 보완요청 전용 버튼이나 미리 작성된 요청 문구가 없습니다. 메모 예시는 “확인이 필요한 서류를 다시 살펴봐 주세요”처럼 사실과 필요한 조치를 간단히 적는 방식입니다. 취업지원패키지의 보완 대상에는 7일 보완 안내가 표시될 수 있습니다. 실제 발송 문구와 절차는 기관이 정한 내용을 따르세요.

## 서류 종류별 안내

아래 날짜와 숫자는 데모에 설정된 기본 기준입니다. 기준 설정에서 사업별로 바꿀 수 있으며, 신청 건은 생성 당시 기준 버전을 사용합니다. 공고문 기준을 여기서 새로 정하지 않습니다.

### 모든 업로드 칸

- 서류 종류는 파일 이름이 아니라 본문으로 확인합니다. 종류가 다르면 잘못 올린 서류를 안내하고, 종류를 알 수 없으면 담당자 확인으로 보냅니다.
- PDF, JPG, PNG를 받습니다. 암호가 걸린 PDF는 다시 제출해야 합니다.
- 화질 점수 0.6 미만은 부적합, 판독 신뢰도 0.85 미만은 확인필요로 처리하는 설정이 있습니다. 이 두 수치는 TF 미확정 데모 가정값입니다.
- 모니터 화면 촬영이 의심되는 경우 자동 반려하지 않고 담당자 확인으로 보냅니다.
- 입력한 발급일과 읽은 발급일이 확실히 다르면 부적합, 비교가 불확실하면 확인필요입니다. 인정 방식은 공고일 이후, 특정일 이후, 신청일 기준 N일 이내, 또는 제한 없음 중 기준 설정으로 정합니다.
- 서류의 성명·생년월일을 본인인증 결과와 비교합니다. 확실히 다르면 부적합, 읽기가 불확실하면 확인필요입니다. 신청자 안내에는 서류 속 다른 사람의 이름을 표시하지 않습니다.
- `주민등록번호`처럼 칸 제목이 값으로 잘못 읽힌 경우 해당 값을 미판독으로 봅니다.

## 자주 묻는 질문

### 서류를 읽지 못했다고 나옵니다.

사진이 흐리거나 서류 종류·필수 항목을 판별할 수 없는 경우 확인필요가 표시될 수 있습니다. 원본을 확인하고, 안내가 다시 제출을 요청하면 서류가 잘 보이도록 다시 올리세요. 데모의 own OCR은 아직 신청 화면 판독 체인의 기본 엔진으로 연결 중입니다.

### 확인필요는 무슨 뜻인가요?

자동 판독만으로 확실히 결론 내릴 수 없어 담당자가 원본을 확인한다는 뜻입니다. 자동 부적합과 다릅니다. 취업지원패키지는 확인필요 서류가 보완 대상일 수 있으며 데모 안내에는 7일 기한이 표시됩니다.

### 개인정보는 어떻게 처리하나요?

데모는 가상 정보와 가상 서류를 사용합니다. 전북AI OCR 설정에서 외부 판독을 허용한 경우에도 응답을 받은 즉시 주민등록번호 뒷자리를 지우고 원문은 DB·파일·로그·API 응답에 남기지 않도록 구성돼 있습니다. 공개 저장소에 실제 서류나 개인정보를 올리지 마세요.

### 파일 이름을 바꾸면 판정도 바뀌나요?

서류 종류 판정에는 파일 이름을 쓰지 않습니다. 서류 본문을 바탕으로 판별합니다.
