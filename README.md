# 전북 청년정책 신청서류 자동 검토 시스템

두배적금과 청년 취업지원패키지 신청 서류를 읽고, 공고문 규칙에 따라 확인한 뒤 담당자가 검토할 내용을 정리하는 데모입니다.

## 해결하려는 문제

도청·시군 담당자는 신청자가 낸 여러 서류를 열어 자격과 제출 상태를 하나씩 확인해야 합니다. 신청자도 서류가 잘못되었는지 접수 뒤에야 알 수 있습니다. 이 시스템은 업로드할 때 서류를 읽고 미비 가능성을 알려 담당자의 확인 부담과 신청자의 재제출 대기를 줄이는 것을 목표로 합니다.

## 핵심 기능

1. 서류 내용을 읽어 업로드 칸에 맞는 서류인지 확인합니다. 파일 이름은 판정에 쓰지 않습니다.
2. OCR(서류 사진이나 PDF에서 글자를 읽는 기술)로 이름, 날짜, 금액 등 필요한 항목을 읽습니다.
3. 공고문에 적힌 날짜·자격 규칙으로 서류와 신청 내용을 확인합니다.
4. 확실하지 않은 항목은 자동으로 부적합 처리하지 않고 담당자 확인으로 보냅니다.
5. 담당자는 원본 서류와 판독 결과·판정 근거를 한 화면에서 확인합니다.

## 한눈에 보는 흐름

**신청자 → 서류 업로드 → 자동 판독·규칙 판정 → 담당자 확인 → 결과 안내**

자동 판독은 판단을 돕습니다. 자격과 점수는 공고문 기준에 따른 규칙으로 계산하며, 불확실한 내용은 사람이 확인합니다.

## 빠른 시작 (약 5분)

필요 환경은 Python 3.12 이상, Node.js 20 이상입니다. 저장소 루트에서 설치합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r demo/backend/requirements.txt
python -m pip install -r engine_v2/requirements.txt
python engine_v2/tools/fetch_own_models.py
cd demo/frontend && npm install && cd ../..
python -m demo.fixtures.make_samples
```

터미널 두 개에서 실행하고 <http://localhost:5173>을 엽니다.

```bash
uvicorn demo.backend.main:app --reload --port 8000 --env-file .env
```

```bash
cd demo/frontend && npm run dev
```

시연용 문서는 가상 데이터로 만듭니다. own OCR 모델은 별도 내려받기이며 저장소에 포함되지 않습니다.

## 현재 상태와 한계

두 사업의 신청·서류 검토 데모와 기존 OCR·규칙 기반 판정 흐름이 있습니다. 자체 OCR `own`의 데모 기본 엔진 연결과 학습 단계, 추출 규칙 보강은 진행 중입니다. 서류 분류 모델은 실험 단계이며 데모 판정에는 연결되지 않았습니다. 문서가 90도 또는 180도 돌아간 경우 자동 보정은 없습니다. 현재 own 평가는 ±2도 이내 기울임을 다룹니다. 알림톡 연동은 제안입니다.
