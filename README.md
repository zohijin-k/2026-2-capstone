# 전북청년 함께 두배적금 — 서류 자동심사 시스템

전북청년 함께 두배적금 사업의 서류 접수·심사 과정을 자동화하는 프로젝트. 정원 1,300명에 12,821건이 몰리면서 인당 7~8개 서류를 공무원이 전부 수기로 심사해야 했고(전주시 기준 심사에 1~2개월 소요), 콜센터에는 자격요건·제출서류 관련 반복 문의가 쏟아졌다. 이 프로젝트는 서류 업로드 단계에서 적합/부적합을 즉시 걸러내고, 자격 요건을 자동으로 점검해서 담당자의 수작업 부담과 신청자의 대기 시간을 동시에 줄이는 걸 목표로 한다.

## 왜 필요한가

- 신청 13,000건 근처, 서류는 인당 7~8개 → 총 10만 건 가까운 서류를 수기 처리
- 콜센터 상담 3,073건 중 38%가 자격요건 문의, 14%가 제출서류 문의 — 안내가 안 돼서가 아니라 신청자가 스스로 확인할 방법이 없어서 반복됨
- '27년 운영계획에 이미 "담당자 중심 확인·안내 → 시스템 기반 자동 확인·분류·알림"으로 전환한다는 방향이 공식적으로 잡혀 있음

## 적용 대상 사업

- 전북청년적금 지원사업
- 취업지원 패키지

## 사용자 플로우

1. 신청자가 정보 입력
2. PDF/이미지 증빙자료 업로드 → 업로드 즉시 서류 적합/부적합 판단 (등본/초본 오분류, 발급일 유효성 등)
3. 전체 서류 제출 완료 후 통합 자격 심사 (소득분위, 지원 횟수 등)
4. 신청자가 AI 판독 결과 확인 → 오류 시 수정/재업로드
5. 최종 제출 → 담당자가 AI 점검 결과와 원본 서류를 함께 확인
6. 선정 결과 확정 및 마이페이지 안내 (추후 카카오톡 알림 연동)

본인 인증이 어려운 신청자를 위한 수동 신청 메뉴도 동일한 검증 절차를 적용한다.

## 참여 주체 / TF 구성

- 전북특별자치도, 각 시군 담당자, 청년허브센터
- 홈페이지 개발사(나루) 및 운영담당자
- 학생 TF팀: **엔진(진)** / **데모 사이트(지빈)** / **대시보드(채운)**

## 폴더 구조

```
.
├── engine/           # 서류 적합성·자격 판단 엔진 (담당: 진) — 상세는 engine/README.md 참고
├── demo_run.py       # 엔진 단독 동작 확인용 데모 스크립트
└── README.md         # 이 문서
```

데모 사이트, 대시보드 코드는 각 담당자 저장소/폴더가 별도로 합류할 예정.

## 일정

- 8/24 회의: 1~5단계(서류 판단 → 통합심사 → 결과안내 마이페이지 → 공무원 심사 → 대시보드) 역할 분담 확정
- 8/24~25: 청년허브센터 개인정보 열람 서약 및 접근 계정 지급
- **9/15 전후: TF팀 첫 회의 — 모든 단계 데모(사용자 플로우를 확인할 수 있는 MVP) 완성 목표**

## 아직 확정되지 않은 것 (TF 논의 필요)

- 서류 실물 샘플 (적합/부적합 예시) — 청년허브센터에서 지급 예정
- 배점표, 중위소득/소득분위 기준, 지원 횟수 제한 등 자격 기준 세부값 — 공고문 확정 필요
- "OCR 신뢰도가 낮다"의 기준점과, 낮을 때의 처리 방식
- 부적합 판정 시 담당자에게 넘길 심사 요청 패키지의 정보 항목 (신청 고유번호, 원본 PDF 전달 방식, 사유서 형식 등)
- 관리자 대시보드 vs 신청자 공개용 대시보드 여부 및 각각의 시각화 항목

9/15 회의 전까지는 위 값들을 팀에서 임의로 정해 데모를 완성하고, 회의 이후 TF 확정값으로 교체하는 방식으로 진행한다.
